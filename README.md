# 📸 InstaConvert — Instagram to PDF Chrome Extension

> Convert any public Instagram post, multi-slide carousel, or reel into a beautifully formatted A4 PDF with one click. 100% private, client-side, and free.

---

## ✨ Features

- **Full Carousel Support**: Extracts all slides in a multi-image carousel post in exact original sequence.
- **High-Resolution Output**: Pulls maximum resolution media directly from Instagram CDN.
- **A4 PDF Layout**: Professional dark-themed PDF layout with aspect-ratio scaling and page numbering.
- **Active Tab Auto-Detection**: Detects active Instagram posts when you open the popup.
- **100% Client-Side**: No external backend servers required; runs completely inside your browser.

---

## 🚀 Installation Guide

### Option 1: Quick Install via Developer Mode (Recommended)

1. **Download**: Download the latest [`instaconvert-extension.zip`](https://github.com/YOUR_USERNAME/YOUR_REPO/releases/latest) from the Releases page.
2. **Extract**: Unzip the archive to a folder on your computer.
3. **Open Extensions in Chrome**:
   - Open Google Chrome and enter `chrome://extensions` in the address bar.
   - Toggle **Developer mode** on in the top-right corner.
4. **Load Extension**:
   - Click the **Load unpacked** button in the top-left corner.
   - Select the unzipped `extension` folder.
5. **Pin & Use**:
   - Click the puzzle piece icon in the Chrome toolbar and pin **InstaConvert**.
   - Open any Instagram post and click **Convert to PDF**!

---

## 🛠️ Usage

1. Browse to any Instagram post, carousel, or reel on [instagram.com](https://www.instagram.com).
2. Click the **InstaConvert** icon in your Chrome toolbar.
3. Click **Use Active** (or paste any public post link).
4. Click **Convert to PDF** and download your multi-page A4 PDF.

---

## 🔒 Privacy & Permissions

This extension runs **100% locally** in your browser:
- No data or images are ever uploaded to third-party servers.
- `cookies`: Used strictly to read the session `csrftoken` so Instagram authorizes carousel media fetching.
- `downloads`: Used solely to save the generated PDF file to your local computer.
- `activeTab`: Used to detect post URLs in your active tab for one-click conversion.
